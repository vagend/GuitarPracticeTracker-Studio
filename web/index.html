Installing

Start it with Start Guitar Practice.command on a Mac or Start Guitar Practice.bat on Windows. Then, in Chrome or Edge, use the install icon at the right end of the address bar (or the Install app button up top). In Safari on a Mac: File → Add to Dock. Once installed it opens in its own window and keeps working even when the launcher isn’t running. Each computer keeps its own practice log; use Export/Import backup to move it.
